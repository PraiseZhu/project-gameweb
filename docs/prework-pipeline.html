未规范 Figma 货架 → 做页可吃的清单。青线是机器闸门，黄线是人确认，绿线是出口。第 7 关双绿才能打包；升 ready 必须主人点头。执行权威：standards/figma-naming/SKILL.md「链路验收口径」。

讨论订正（必须按这个执行）
  1. 左侧 Page 链接可开工。给 Figma 左侧 Page（CANVAS）即可拉整张画布，再用 --page 选端。不要只点画布里某一个 PC/手机 frame。
  2. 第一步 draft 是清单数据，对 Figma 快照不对截图；未规范必须同时 --status draft 和 --name inventory-unnamed-392-24190（冒号改短横线；CLI 会换 :）。缺一个 CLI 失败。
  3. 导图不是每层一张。必导整页 + 全套组件集。弹窗图会导出，但判断包/G2 只收 page/set jpg。
  4. 目录不是自动命名器。尝试扫组件集/弹窗，只给弱前缀建议；弹窗 0 命中正常。散图和划动看本页图。
  5. 词表是漏项保险。CARD_ART_RE / IMAGE_BODY_RE / CLIP_RE 覆盖不同；裸词「划动」不亮灯。没撞词表仍要看图。
