## 适用范围（✅ 已定 2026-11-16）

- v1 只覆盖整屏切换（onepage）专题页，含本次实际约定的语言集合和 PC／手机端。
- 长滚动页、瀑布流长图页和其他不是 onepage 的页面类型另立规范；不套用本版的 `fix/` 出现规则、切屏、手势、首屏 100vh 或 onepage 轮播规则。
- 规范没有覆盖的新页面类型必须先停下来上报，不自行把本版规则扩展过去。
