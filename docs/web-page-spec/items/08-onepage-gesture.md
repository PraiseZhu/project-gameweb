### 8.10 修订（✅ 已定 2026-11-12）

**底栏就是 `fix/`**：和 3.1 一致，本稿底栏就叫 `fix/底部固定背景`（只画在第 2～6 屏）。稿上没有底栏就不生成；有几屏画了，就在那几屏显示。开发侧的进出动画（从无到有时 0.32 秒滑入，从有到无时 0.26 秒滑出）适用于任何“只在部分屏出现”的 `fix/` 固定块。

**下一屏箭头需要在命名上标出来**。现状：本稿里箭头叫 `img/下滑示意箭头`，是一张图，机器看不出它能点、点了去哪。现行规范里 `@sec=` 只能写数字，没有“下一屏”的写法。

建议（写法最终在改命名规范时定，F12）：
- 箭头写成 `btn/下一屏@sec=next`：可点击，点了去下一个可见屏；
- 开发侧的行为都挂在这个标记上：每 1.6 秒轻跳；最后一屏自动翻转成“返回首页”，点了回第一屏。设计稿不用另画“返回首页”的状态；
- 一页只允许一个 `@sec=next`。
