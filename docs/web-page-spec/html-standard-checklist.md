## 1. 基准与边界

- 基准是开发侧 ews2026 HTML 样本。采用其最终结构和呈现，叠加用户已经明确确认的修改；不把所有修改都称为“开发原有标准”。
- **沿用**：来自开发样本并已确认；**已确认调整**：用户在样本基础上修改的要求或明确保留的 Gameweb 能力；**已确认的暂定建议**：本版明确采用的临时要求，未来开发正式标准优先，不冒充开发原有标准或已完成实测。
- 设计侧／Gameweb 交付符合本规范、具有静态 DOM、无需构建即可放上静态服务器的 HTML 页面及配套目录。正式配置、组件接入、数据发布、部署、缓存和线上验收属于开发后续。
- 页面做成什么样以实际设计内容为准，不补画不存在的模块。语言按实际需要，可以只有一种；样本五语不是通用要求。
- 本版 v1 只覆盖整屏切换（onepage）专题页。长滚动页、瀑布流长图页另立规范，不套用本版 fix、切屏、手势、首屏与 onepage 规则。
- 本轮暂停新增议题和制作方案；已经排除的上线事项不再转成设计侧任务。

依据：[范围与版本](items/02-scope-version.md)、[语言范围](items/10-i18n.md)、[交付职责](items/17-launch-readiness.md)。

### 1.1 适用范围与缺失处理

- 本版覆盖 onepage 及本次明确约定的 PC／手机端、语言和模块。实际稿件提供什么，就制作什么；不把一个游戏样本的模块数、四张卡或五种语言推广成通用要求。
- 页面结构采用开发样本的组织方式；尺寸、位置、字号、间距等数值来自设计清单，不能目测补数。当前已定换算适用于二倍稿，其他倍率或新页面类型须明确后处理。
- 约定范围内缺必需稿件、端别、页面状态或组件外观时，制作前停止并说明缺什么；不补画、不猜、不以局部页面冒充完整交付。用户明确缩小范围后，才按新范围核对。缺稿补齐后重新出清单并从头走对应检查，不沿用缺稿期间的猜测或临时补画（原 14.1.5）。
- 外语文案按已有本地化来源、字体按声明处理，不因无独立外语设计稿一概认定缺稿。预留公共组件、提示条等已有固定规则的内容，也不等于缺设计。
- 清单／交接包的具体生成、标记和补齐方法归流程；本版定稿不自动修改现行命名规范或工具。未来新样本、开发正式标准或明确修订应记录版本和来源，不静默放宽要求。

### 2.1 可直接部署的含义

目录中每种实际需要的语言有独立 HTML；css/ 放样式与 font/ 字体，js/ 放页面脚本及集中配置，assets/ 平铺图片、视频等素材并包含 manifest.json，另有 README.md。集中配置文件名留流程确定，不在此另定新文件名。

- 从普通静态服务器打开本次交付的语言入口，无额外编译、构建或模型下载步骤，控制台不能报错；部署包不携带用于整页重建的 model.json／model.json.gz 运行模型，不影响约定业务数据 JSON（原 1.2～1.3）。
- 主体 DOM、标题、正文已在 HTML 内；可变列表可用 template 生成重复项，JS 可更新数据、状态和组件衔接，但不能重建整页主体。
- HTML 初始保留 no-js 标记，脚本启动后移除。禁用 JS 时静态内容和图片仍可见、空懒加载占位隐藏；不要求禁用 JS 后仍能切屏或读后台数据。
- QA 是独立外壳：页面不依赖壳，壳不改变产品页的成品要求。评论、清单、handoff 包、检查截图及差异图不混入部署目录；素材 manifest 应随包保留。
- 正式网址／数据地址／组件尚未接入时，按本规范的缺省状态正常显示；“可以部署”不代表正式服务已接通或上线验收完成。

### 3.1 结构、排布与层级细则

1. 屏、固定块和内容模块均有明确身份；内容模块可多层嵌套。共用固定块只保留一份，位置及显示在哪些屏按实际设计／明确配置，不强制顶部导航、底栏和前景层全部存在。
2. 每屏按满铺背景与居中内容舞台组织。PC／手机各取对应稿数据；当前 PC 基准舞台为 19.2×10.8rem。背景可按 cover 裁切，不能把背景铺满与内容舞台缩放混为一套规则。
3. 可增减的列表、导航、TAB、社媒和开关模块，按已明确排列方向、间距、对齐、内边距、换行关系排布；增减后收拢，不留空卡或无依据的空位。上游自动布局信息如何抽取见流程待办。
4. 设计中已有图层按原遮挡顺序，包括固定块、前景、模块和内容；不能统一把所有前景放在正文之上。弹窗、展开菜单、语言层、提示条等弹出内容位于最上层；同一时间只开一个弹层。
5. 图层 z-index 采用变量或按明确顺序生成，正文不散落无依据的层级数字。未画出的固定模板内容按已定模板处理，不借此新增设计模块。

### 3.2 网页文字、底图与盖层

- 除 bg/、kv/ 固定素材外，设计中的 live 文字节点做网页文字，即使在 img/ 组里也不烘焙进位图；已转曲或原图自带的艺术图形按素材处理。CSS 无法保留的复杂文字效果由设计先转曲，不能由生成器自行截图替代。
- 2026-11-19 用户明确修订：bg/ 背景及 kv/ 各层作为固定素材整体导出，内部可编辑文字也随素材导出，不隐藏、抽离或另做网页文字，也不要求先转曲；该例外不扩大到 img/。kv/ 保留独立素材分层，视差按明确规则接入，不因前缀自动启用；背景 cover、各端素材和内容舞台分离要求不变。
- 每页首屏一个 h1；有普通分区标题时用 h2，每屏最多一个分区 h2。标题组可包括水印／装饰，但不凭空补装饰。
- 文字下方非文字内容构成底图；上方与文字重叠的内容分成盖层，保持遮挡；上方但不重叠的内容可并入底图。文字遮罩或特殊混合无法分层保持画面时，先报告并由设计处理。
- 底图和盖层均以所属模块左上角为定位参照，位置、宽高来自清单并换算为 rem；图层框和实际导出框分别记，阴影／外发光造成的外扩按真实偏移保留。
- 模块宽高按稿锁定；超长文字在模块内按既定换行／截断处理，不能撑走图层或靠外语内边距补偿来硬凑盖层位置。两端分别使用各自数据。
- 素材复用以同母版、同变体且未改外观的实例为依据；换图、换色或改尺寸的实例单独处理。相同导出素材可去重，这不授权删除随包保留的历史／备用文件。

### 4.1 代码组织细则

- class 为有含义的小写英文、数字和短横线；模块英文短词最多两个词，不重复类型词。网页模块名按已明确的“英文短词-类型”对应；同名模块外壳相同，内部差异由子模块或变体区分，不同结构不能静默同名。推荐词表不强制；具体设计稿新前缀见流程 F1。
- 样式用 class，业务元素查找用 data-*，状态用 is-*；不是声称开发原样本已经完全不依赖 class。按钮用途说明复用同一份已明确动作／目标，不能另让 AI 猜一个 aria-label。
- styles.css 依次按全局、骨架、各屏、模块分段并注释；颜色、字体、时长在开头定义变量。外语／手机的共用参数通过变量覆盖，实际布局差异仍放对应样式文件。
- 禁止静态逐节点行内样式。页面自己的静态尺寸和样式写到文件中；这一约束不把已有交互中的运行时状态变化误称为静态排版。
- !important 仅保留强制隐藏／不可点、无脚本兜底、关闭中的弹层以及覆盖公司组件样式等既定用途；普通样式冲突用选择器解决。
- 页面逻辑 main.js 使用立即执行函数及严格模式；无页面框架／第三方库和构建依赖。公共组件接入后单独文件、保持原样，衔接写在页面代码中，正式接入由开发负责。
- 可使用样本已有的可选链、inert、dvh、:is()、matchMedia、ResizeObserver、visualViewport、async/await、fetch。最低浏览器版本、额外内置浏览器适配不在本版另定。
- 开发需填写的数据地址、语言网址、社媒链接与地区组合、页脚／埋点等既定参数集中到一个配置文件；不因集中配置把 SEO、正式分享内容等重新纳入 Gameweb 输入。

- PC：1280×720、1366×768、1440×810、1440×900、1840×1000、1920×1080、2560×1440、2560×1080、2560×720。
- 手机／平板：320×568、375×667、375×812、390×844、812×375、844×390、690×829、768×1024、1024×768；另查 1024／1025 分界往返。

### 5.1 固定数值补全与适用范围

- 当前二倍稿数值 ÷200 得到 rem；设计元素尺寸、位置、字号和间距使用 rem。根字号适配公式使用 vw／vh／dvh；px 的既定例外是断点、公司组件及补丁、系统值兜底。
- 顶部导航使用 --nav-unit：超宽屏封顶 min(100vw / 19.2, 1.08rem)；侧边固定块用 --social-unit 随宽度缩放。视口比例超过 8:3 时，侧栏的二维码／气泡朝屏幕内侧展开，不能照搬样本“总向左”。
- 手机宽度 ≤750px 时，标题区留白按已定样本的 clamp 方式随屏高收紧；不自行推导新的间距值。≤1024px／≥1025px 是两端布局分界，不把 750 当成另一套端别分界。
- 尺寸变化立即结束在途转场，导航／TAB 选中图对齐；保留当前屏、TAB 与轮播页。跨端时关闭菜单和弹层，切换对应端素材。
- 上列 18 种视口及 1024／1025 往返属于已定布局验收范围；设备预设放 QA 外壳，不嵌入产品页面。像素比较的截图组合与阈值另属流程。

### 6.1 语言与字体细则

- 仅输出本次约定语言，并设置正确 html lang；多语共享骨架、class、样式和脚本。允许的差异包括文案、语言图片、外语字体字号、地区社媒组合以及开发后续的 SEO／分享、埋点和页脚参数。
- 运行提示如“待公布”“下一屏”“返回首页”集中在 messages[语言]，已有译文可复用，新增提示只补齐本次实际语言。
- 稿上有语言菜单才保留，链接能力面向独立语言页；正式地址由开发上线前填写。设计阶段用 QA 外壳验语言，不新增产品菜单预览跳转或与 QA 的绑定。
- 各语言成品来自同一份已验收结果；交付前不能拆出后单独手改某一种语言，要回到同源结果修改、重验并重新输出。操作方法留流程 F16。
- 简中字体按稿；其他实际语言按角色（标题、正文、数字，必要时按钮）的字体声明，不自动套样本固定组合。无该语言需求，不要求其字体或声明。
- 字体使用真实字重文件或可变字重，完整字库与原始字体格式，放 css/font/；每种字体具备文件及来源／许可说明。缺指定字体先报告，不能悄悄用系统字代替还原；加载期间 swap 的临时系统回退不等于最终字体可缺失。
- 未使用字体不进包；完整字体计入整包体积。历史图片保留规则不覆盖这条字体要求。

### 6.2 位图、SVG 和 manifest 的成品要求

- 位图每次从无损 PNG 源直接编码；不能串联 JPG、旧 WebP 或重复有损压缩。实际 alpha 任一像素小于 255 才算透明，不仅判断是否存在 alpha 通道。
- 无损 WebP 的 alpha 逐像素差为 0、可见像素 RGB 一致；完全透明像素的隐藏 RGB 不作为误报。透明边缘在黑、白及实际底色下正确。
- 有损 WebP 保持尺寸和透明要求，细线、Logo、渐变、颜色无可见劣化。quality=90 不是“保留 90% 画质”；编码器与版本需要可追溯。SSIM／PSNR 等工具、阈值和取样在流程讨论。
- SVG 必须能可靠保持整个切图边界的画面，没有嵌入位图、外部依赖或失效效果，导出框正确。包含位图或未验证效果时采用位图；无法读取完整结构或无法建立可靠基准时不能假装验证通过。具体分类／导出机制在流程中落实。
- manifest 至少保留文件来源节点／实例、格式、尺寸、字节与校验值，并增加 module、layer、box，记录所属模块、底图／盖层及相对坐标与导出框。
- 格式转换追溯字段：classification（raster／vector）、sourceFile、sourceSha256、deliveryFile、deliveryFormat（webp／svg）、deliverySha256、width、height；位图另记实际 alpha 判定、encoder、quality、lossless、method。不能用 manifest 替代缺失的资源文件。
- 原始／历史／备用素材可以随包保留，未引用不构成失败或自动删除理由；当前运行引用必须全部存在且可解码。转换后仍须用最终素材验页面。

### 6.3 暂定视频和体积建议的计量

- 背景视频 MP4 + H.264/AVC，音轨数量为 0；静音播放不等于无音轨。faststart 要求 moov 位于媒体数据之前。
- 单视频 ≤15,000,000 字节，整包 ≤120,000,000 字节；这是已确认暂定建议，非开发正式门槛，不与旧 Pack 的 MiB 预算混用。
- 整包按实际交付目录全部文件字节统计，不按 ZIP 大小，不只算运行引用；历史图片／备用视频、完整字体、脚本、HTML、manifest 均计入，同一文件被多页引用不重复累计。
- 单视频格式与上限针对当前页面实际使用的视频；历史备用视频保留并计入总包，不自动转码／删除。外部网站播放的视频不作为本地文件计入。
- 超限报告具体文件和差额，不能为过线删除历史素材、裁剪字体或降低已定画质；开发后续提供正式标准时据其明确修订。只留视频入口时不要求现在生成或压缩视频。

### 7.1 数据读取、缺省与显隐

1. 需要数据的页面从一个已配置 JSON 地址读取。初始化时请求一次，带时间戳参数、credentials: omit、cache: no-cache；地址为空不请求，不给页面新增轮询、超时或自动重试。
2. 根元素记录 loading → ready／unpublished（404）／unavailable（其他请求或解析错误）。未填或读不到时保留静态默认内容；示例姓名、比分等不能当真实数据，使用已定义“待公布”。
3. 默认内容和后台内容是两份来源；请求返回后在浏览器里覆盖显示，不把后台更新误写成 HTML 文件本身已经更新。默认值过期风险保留在流程 C2。
4. 接口内容明确区分整屏／模块开关、列表、字段及控制显示／切换的状态值。列表按条数生成；固定槽位按既定结构填值，不能把所有数据组一概做成增减列表。
5. 数据开关隐藏屏时，指向该屏的导航一起隐藏；剩余导航按明确布局收拢，翻屏与选中位置按可见屏重新计算。
6. 普通文字／数字／图片值直接共用；按语言分组的值读取当前语言项，缺当前语言的条目不显示。已有键对应：zh-CN→zh_CN、zh-TW→zh_TW、en→en_US、ja→ja_JP、ko→ko_KR；不代表每页必须具备这五种语言，新增语言需明确映射。
7. 可变范围可按项目扩展至日期、奖金、标题等运营常改内容；是否可变由明确业务范围决定，不让 AI 看外观猜。后台建字段和正式发布由开发负责，其支持能力仍待具体项目核实。
8. 外部文字通过 textContent 写入；外链仅 http(s)。数据读取／展示是 Gameweb 的交付能力，正式接口接通归开发，内容真实性归需求方。

### 8.2 导航、TAB、轮播、弹层细则

- 导航选中背景位于对应按钮中心，320ms 滑动、略冲过再回退；既定冲过量约为 0.12×--nav-unit。TAB 的冲过量为 0.12rem。同组选中图必须相同才共用滑动；不同则各自换图，不强行滑动。首次加载不播滑块、连续操作从当前可见位置接续。
- TAB 使用 button 的 role=tab、aria-selected、aria-controls 对应 role=tabpanel；未选面板 hidden。重复点当前项不重播；只有一个阶段时按实际按钮宽度居中。
- 卡片轮播按实际条数／设计每页数量向上取整；不同内容轮播按设计的独立页面模块数。圆点数跟实际页数，不按稿上复制的圆点数量硬写。
- 多页轮播可向前／向后无限循环，越过末页时沿同方向无缝衔接；横滑同样循环，非当前页 inert。末页不足不补卡，整体居中。
- 0 条时只显示已定义空状态，卡片、箭头、圆点和页码均隐藏。1 页时显示卡片，隐藏箭头／圆点，只有稿上存在页码才显示 01/01。多页正常显示，页码“当前／总数”两位补零；没画页码不生成。
- 菜单与语言层 200ms 渐入渐出；打开移入焦点，关闭还给触发按钮；关闭按钮、Esc 和语言层已规定的外侧点击可关闭；互斥、关闭中不可点，快速反向操作从当前状态接续。不能给所有弹窗擅加同一关闭策略。
- 社媒采用新窗口 http(s) 链接、rel=noopener noreferrer、可识别的用途说明和内联 SVG 图标；微信二维码支持悬停／键盘聚焦，手机隐藏微信。具体地区组合与链接由开发配置，不把样本按钮数量定死。
- 后台外链卡片支持点击／键盘激活；无链接或格式不对，按当前语言提示“待公布”，封面失败使用已有默认封面。外链视频播放由目标网站处理，不新增本地播放器。

### 9.1 动效对象与播放约束

六类为：普通分区标题、内容模块、交互组件、前景装饰、首屏组合开场、页面切换。同类对象在同种触发下采用同一套已定规则；固定组与重复组可共用基础效果，但整组、逐项、分批的作用单元必须明确。

### 9.3 首次与返回首屏的时序

首次等待当前端背景、slogan 加载／解码成功或失败，到可绘制帧后从 0 计时：0ms 背景开始；320ms 顶栏与手机底栏开始；440ms 顶栏晶体开始；480ms 社媒开始；600ms slogan 滑入开始；700ms 内部闪烁开始；约 1300ms 首次开场阶段结束，满足条件才尝试背景视频。

返回首屏时背景仍渐显，slogan 滑入延迟 80ms、闪烁延迟 180ms；不重播顶栏／社媒的首次入场。1300ms 是动画计时，不是资源等待超时。只对实际设计中存在的对象应用，样本手机首页底栏等不能覆盖“按实际稿显示”的规则。

### 10.1 加载、失败与保护细则

- 首次只预加载当前语言、当前端的首屏静态背景，不同时预加载 PC 和手机背景；非首屏图片按需请求。slogan、导航、当前可见内容及必需 CSS／JS／字体照常加载。

- 动态头像或封面地址缺省／失败，回到已有对应默认图；默认图也失败不循环换图或不断请求。视频加载／自动播放失败恢复静态背景和 slogan，其他内容正常，不新增错误弹窗。
- 普通背景图、Logo、装饰图和默认图失败后的统一显示方式未加入本规范，由开发按具体项目处理；不能把这个职责排除解释为允许缺素材交付。
- 页面资源没有额外等待截止时间、超时主动中止、自动重试或定时轮询。挂起时维持既有等待行为；不改变浏览器／网络自身超时，也不禁止用户刷新。工具执行超时、动画计时和提示条消失计时不在这条限制内。
- 不另定首屏秒数、Lighthouse、LCP／CLS／INP 等数值门槛。慢网测试中的延迟不是页面超时标准；体积建议和已定加载行为仍需满足。
- 正文选择、复制／剪切、原生拖出、右键限制同时覆盖产品页与 QA；输入框、textarea、可编辑区域和明确复制按钮可正常使用。保护不能误伤按钮、滑动、键盘和编辑，也不承诺防截图或彻底防下载。
