# G/H 最终包与交接方案（待确认）

更新日期：2026-11-20。来源：讨论记录 R218～R219。只是方案，不代表工具已实现或页面已通过。

## 1. 包里放什么

直接按已定开发标准（H01～H05、H23、H43、第 1 项、第 12 项），不另定格式：

- 每种实际语言一份独立 HTML；`css/` 放样式和 `font/` 字体；`js/` 放页面脚本和集中配置；`assets/` 平铺图片、视频等素材并带 `manifest.json`；另有 `README.md`。
- 集中配置文件名用标准里的示例 `js/config.js`，正式网址、社媒、接口等由开发填写。
- QA 外壳、评论、清单、交接包、像素门产物和截图不进包。
- 原始、历史和备用素材随包保留，未引用也不删。

## 2. G：打包后核对

- 只用设计师最后确认的版本：单语言取 D，多语言取 F。
- 在打包后的文件上重新核对：目录和文件符合上面标准；页面引用的文件都存在；不该进包的材料没有混入；字体和编码正确；`manifest.json` 与实际素材一致；页面画面和交互与确认版一致。不能只验打包前页面。
- 未被引用的历史素材不算错误。
- G 不再压缩、不改效果。发现问题回源头点对点修，复验受影响部分；影响画面或交互的部分交设计师再看。

## 3. H：冻结交接

- 冻结版本，记录版本号、文件清单和校验值、检查结果及对应验收记录。
- 附开发待办：正式外链、接口、上线相关事项，并写明本次语言和端别范围。
- 冻结后再改按新版本处理。设计交付完成不等于正式上线，开发负责的部分另行验收。
