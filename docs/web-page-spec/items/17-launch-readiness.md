## 范围和已有分工

本项明确 Gameweb 交付包的要求，以及开发接手后的上线职责。正式配置、发布和线上验收属于开发；本轮只定稿文档，不实现、不部署、不请求正式接口。

## 17.0 交付边界（✅ 已定 2026-11-16）

**设计侧与 Gameweb 只负责交付一份符合开发要求和本规范、包含静态 DOM 内容、可直接部署的 HTML 页面／静态目录。开发接手之后的正式上线流程归开发侧。**

- Gameweb 交付前负责设计稿对应的 DOM、样式、已定交互、素材、语言验收结果和接入口，交付物应能作为静态页面直接部署。
- 开发接手后负责正式网址与配置、公共组件接入、真实数据和埋点、页脚正式内容、地区／合规处理、正式分享接入、部署、缓存和线上核验。需求方在开发负责的环节确认业务文案、真实数据和发布条件。
- 本项后续条款用于划清“交付前是否具备可交付条件”和“开发接手后的正式发布职责”，不把开发侧上线步骤倒灌为设计稿、命名或 Gameweb 出页输入。
- 交付前的 QA／机器验收仍属于 Gameweb 的交付质量检查；它不等于正式环境已经部署、正式接口已接通或线上业务内容已经发布。
- 页面内 Logo、已定页面交互与静态接入口属于交付内容；网页标题、简介、关键词、canonical、favicon、分享文案／图、正式域名、法律信息、埋点和真实数据，按本项已定分工或开发接手后处理。

## 本轮核查的开发侧依据

读取本机 ews2026 当前 cn/tw/en/jp/kr.html、js/main.js、js/tracking-boot.js、css/styles.css 和五张分享图，并对照提交 39f9d71 的 README。当前工作区存在未提交改动；这里记录实际文件，不声称它们等于线上当前版本。

- 五语 head 均有 charset、viewport、format-detection、title、description、keywords、canonical、Open Graph、Twitter Card、favicon 等声明。
- 分享类型为 og:type=website，Twitter Card 为 summary_large_image；五张分享图实际均为 JPG、960×540，与 head 声明一致。
- 只有简中入口加载 tracking.js 和 tracking-boot.js；README 说明海外统计参数待确认，已有验证是本地模拟，未进行线上统计验收。当前只接基础生命周期事件，没有绑定点击／曝光点位。
- 页脚按语言传入 appId、region、language；协议、备案等由公共组件及其配置提供。
- 页面存在真实 button／a、focus-visible、aria 标签、隐藏面板 inert、统一提示条 aria-live；图片禁选取／拖拽。不能据此声称已通过完整无障碍或合规验收。
- 本地 HTML 未见 hreflang／robots meta，目录未见 robots.txt 或 sitemap.xml，页面代码未见 Cookie 同意界面。不能据此断言整个正式站点没有站点级配置，也不能直接认定每个页面都必须新增这些功能。
- 本轮没有请求正式网址、分享抓取器、数据接口或统计服务；没有上线、真实设备、分享卡片实际展示或浏览器故障实测。
