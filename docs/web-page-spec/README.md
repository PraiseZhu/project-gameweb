# Gameweb 交接总览

**2026-11-17 新任务决定：** 在 Gameweb 内建立独立的 [one-page标准流程](../../standards/one-page/README.md) 分组，承接后续流程改革，独立于伊瑟、火炬等现有项目。该分组已整理 [最终交付与验收标准](../../standards/one-page/delivery-and-acceptance.md)，以本目录的已定成品细则为依据，列明交付物、H01～H43 及各项验收条件与证据。本目录继续维护完整成品细则、流程待办与制作资料要求；具体新流程尚待讨论和实施。下文的原 session 收尾记录保留其历史语境。

**现阶段请开发提供这 4 类东西，都是 Gameweb 做页面前会用到的：**

1. **Onepage 完整 Skill**：制作 ews2026 时使用的版本，以及它实际引用的模板、脚本和说明文件。
2. **页面制作会复用的文件**：模板、闪烁动效等资源；复用样本字体时补缺失的来源／许可。工程已有，只确认版本、补缺件，不用重复传或提供整个组件库。
3. **数据字段说明＋JSON 样例**：字段叫什么、类型是什么，哪些是列表／开关，语言和空值怎么处理；已有字段命名规则一起给。用来生成页面读取和显示数据的代码。
4. **已有制作／验收方法和要求**：怎样从 Figma 取数、切图、检查还原度，以及已有的图片／字体、视频／包体积、浏览器／性能要求。有现成的给过来，没有就说明没有，不用另写一套。

**现在不要后台账号、权限和管理手册，也不要正式组件接入、埋点参数、域名、真实业务数据或上线配置。** 那些属于开发拿到设计侧成品后的工作。
