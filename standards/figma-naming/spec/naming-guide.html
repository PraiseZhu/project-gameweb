sec/

页面分区

想要把页面分成第 1、2、3 屏

标在标在每个页面分区的外框。编号是排序和导航的依据。

sec/1-首屏

注意编号以正整数开头，同页不能重号。可隔着无前缀布局容器；不要嵌套 sec，也不要放在 img、switch、modal 等语义层里。各分区须属于同一逻辑父层。

依据：§1 / A2
fix/

视口悬浮

想要让导航或按钮钉在屏幕上

标在标在悬浮层容器；里面能点的入口仍标 btn/。

fix/侧边导航@from=2

注意不写 @from 就进页固定；@from=2 表示从第 2 屏起出现并固定，第 2 屏必须存在。首屏随页面滚动的按钮另放在 sec/1 里。

依据：§1、§2 / A2
grp/

通用模块容器

想要把有独立语义的一组子模块作为一个整体

标在标在需要被页面结构、布局、关系或验收单独识别的容器。

grp/模块边界

注意纯排版包装、遮罩和技术 wrapper 不标；具体类型明确时优先用 panel/list/card 等类型。

依据：§1 / G1
list/

条目集合

想要把同类条目组织成可重复集合

标在标在列表容器根；直接重复子项用 item/。

list/集合

注意需要 Auto Layout 或等价排布声明；普通排列不标。

依据：§1 / G1、G2、G4
item/

重复条目

想要标记列表中的一条重复项

标在标在 list/ 的直接重复子项。

item/条目

注意只在 list/ 内作为条目边界使用；内部继续按现有角色命名。

依据：§1 / G1、G2
ref/

参考稿

想要放说明稿，不交给前端做

标在标在整份滚动示意、状态说明等参考内容的外框。

ref/滚动效果说明

注意整个子树被忽略，不检查、不报警。不要把真正要交付的页面或素材放进去。

依据：§1
img/

静态图片

想要导出装饰图、图标、美术字

标在标在要整体导出的图层；美术字即使是 TEXT，也可明确标成图。

img/首屏标题

注意不是任意外层编组都标 img。可改文字不加前缀；多语言换图看场景 F，可替换整图看 H。img 不挂 @ 参数。

依据：§1、§3 / A1、A6
bg/

大面积背景

想要导出内容背后的大底图

标在标在实际的背景素材层。

bg/首屏底图

注意只表达大底图身份，不包住整屏按钮和文案。可替换标记不支持 bg，不要为了可替换而改成 img。

依据：§1、§5 / A1
kv/

KV 视差层

想要让背景、角色、前景分层视差

标在标在同一父层下各个要分别运动的视觉层；外面的纯编组保持原名。

kv/角色@parallax=0.4

注意系数为 0–1。只有一层无法体现视差；普通静态图用 img，大底图用 bg。KV 外层容器不要整块标 img。

依据：§1、§5 / A1
btn/

可见按钮

想要让一个可见元素可以点击

标在标在实际可点击的控件根层。

btn/播放@go=modal/视频弹窗

注意可选 @link / @go / @sec / @lang；实际动作仍要配置。普通按钮内部要切的图仍需命名；布尔合成按钮整体导出，不给 Subtract 零件逐个加 img。

依据：§1、§2 / A3、A8
hot/

透明热区

想要在画面上盖透明点击区

标在标在透明命中区域，而不是下面的视觉图片。

hot/官网入口@link=official

注意可用 @link、@go、@lang；不能用 @sec。可见控件用 btn，透明覆盖区用 hot。

依据：§1、§2 / A3
modal/

独立弹窗

想要点击后出现一扇弹窗

标在标在独立的弹窗 Frame，放在页面正常稿之外。

modal/视频弹窗

注意入口 @go 抄弹窗完整图层名，不写 node id；目标必须唯一。多颗入口可开同一窗。窗内播放、关闭按钮不要写开窗 @go。

依据：§1、§2 / A3、A7
dropmenu/

开合菜单

想要点开菜单，再点选一项

标在标在菜单组件集根层；用变体表示关闭和展开。

dropmenu/语言菜单

注意状态轴的值集合必须恰好是小写 on、off，轴名不限。不能写 @on、@off、@state。PC 和手机都适用；已画成 btn → modal 的保持弹窗。

依据：§1 / A9
dyn/

动态内容

想要显示倒计时、进度或当前选值

标在标在运行时会更新的组件容器。

dyn/活动倒计时

注意内部零件免前缀语法与图像未命名报警。前缀声明动态身份，具体数据来源与业务逻辑仍由下游接入。

依据：§1
mix/

图文混排

想要保留日历、列表的图文结构

标在标在日历、奖励列表等图文混排大块的容器。

mix/活动日历

注意只需命名容器，内部零件免前缀语法与图像未命名报警。无前缀图片填充叶子自动拆切图，TEXT 保留文案；不是把整块导成图片。

依据：§1 / A8
scroll/

滑动视口

想要让列表连续横滑或竖滑

标在标在可滑动的视口框；第一个子层必须是内容轨道。

scroll/奖励列表@y

注意默认横滑，也可显式 @x；竖滑写 @y。轨道直接子项是 item。普通 scroll 内图片仍需命名；在 mix 内时保留滑动和自动拆图规则。

依据：§1、§2 / A5、A8
switch/

切换器／轮播

想要轮播或切换一整份内容

标在标在切换内容的容器。

switch/玩法轮播

注意页签条用 tab，圆点用 ind。不发明 swpage/。连续滚动列表用 scroll，切换整份内容才用 switch。

依据：§1 / A4
tab/

页签条

想要点击页签切换内容

标在标在 switch 对应的页签条容器。

tab/职业页签

注意表达页签切换身份，不是普通外链按钮。它本身不是切图角色；内部需要独立导出的图片仍需命名。

依据：§1 / A4
ind/

轮播指示器

想要用圆点或菱形表示轮播进度

标在标在指示器组件／实例；同组可同名，序号按同级排列。

ind/轮播进度

注意嵌在 switch 内可确定归属；否则最近 sec 内只能有一个 switch（无 sec 时看体检根）。组件集各变体整体切图，内部小钻石不命名。

依据：§1、§6 / A4、A8

03@ 参数：只接在允许的前缀上

动作参数选填；写了就要合法、目标有效。img / bg / modal / dropmenu 等不挂这些参数。

写法适用前缀作用与边界完整例子
@link=<key>btn / hot跳转到配置中的链接填业务 key，URL 放配置。btn/官网@link=official
@go=<state>btn / hot状态转移；开窗指向弹窗名开窗目标须存在且唯一；不要写图层 id。btn/预约@go=modal/预约弹窗
@lang=<codes>独立 btn / hot只在指定语言出现逗号分隔小写五码，无空格、空项、重复码；壳内和弹窗内容里禁用。btn/适龄提示@lang=cn
@sec=<N>btn点击滚到第 N 屏N 为正整数，对应分区必须存在。btn/玩法@sec=2
@from=<N>fix从第 N 屏起出现并固定N 为正整数，分区须存在；不写则进页固定。fix/导航@from=2
@parallax=<0–1>kv这层的视差系数取值 0–1，需同父层多层配合。kv/前景@parallax=0.8
@x / @yscroll横滑／竖滑纯标记，不写等号和值；默认横滑。scroll/奖励@x

05交稿前，把这些边界过一遍

01 · 先判断需不需要前缀

只有切图、交互、分区、行为需要前缀。普通编组保持原名；可改 TEXT 不加前缀。美术字标 img 后，即使是 TEXT 也按图消费。

02 · 名字写用途，不写猜谜

推荐小写 + 半角 / + 用途名。前缀大小写、斜杠两侧空格、全角 ／ 兼容，反斜杠错误。容错不适用于语言码、on/off、[replaceable]。

03 · 只有这 19 个前缀

不自造 txt/、part/、swpage/、dropdown/、select/、menu/、tag/。纯布局名可保留；Group/2 等 Figma 自动类型名不当作前缀。

04 · 参数选填，但写了就要对

未知参数、空值、非法值、挂错前缀都要改。@lang 不允许重复参数、重复码、空项或空格。并非所有前缀都能挂参数。

05 · 同名检查有边界

同一父层的已命名层要能区分用途，不要只用数字掩盖不同用途。ind 同组可同名；组件集直接变体、ref 子树除外；不同语言变体内同名按钮父层不同。

06 · 切图看身份，不看 Export

img / bg / kv 命名即切图意图，不必另勾 Export。Export 仅覆盖格式与倍率。不要整图包住仍需交互或改文案的结构。

07 · 文字尺寸与自动名

TEXT 名等于自身文字内容（去空白）时，内容中的斜杠不触发前缀语法报警，不免其它规则。长段落定宽换行；紧凑控件定宽定高，要注意文案变化。

08 · 声明功能，不代表已接好功能

btn 动作可由参数或配置提供，dyn 仍要数据，@lang 显隐仍要验。清单中 @lang 节点仍保留，不因某语言不显示就改成 unknown 或 skipped；开窗目标始终要校验。

09 · 体检提示与交接硬闸有区别

必改项要修；“必须回答”可说明接受原因；“提醒”先核实。ready 不表示所有命名都正确。出清单会拦无目标分区、指示器归属、无轨道、分区结构、非法参数等确定性错误。

10 · 不能用豁免跳过必改项

只有“必须回答”和“提醒”能按条件豁免；需结构条件、命中范围、有效期与复审。完整 26 条错误码见正文 §6；豁免机制见 §7。
