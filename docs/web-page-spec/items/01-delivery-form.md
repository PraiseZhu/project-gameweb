## 开发侧（ews2026）

- 交付物是一个静态目录，直接上静态服务器即可，不需要构建：
  - 该开发样本的语言文件是 `cn/tw/en/jp/kr.html`，不是其他页面必须具备的固定数量。
  - `css/`：`styles.css`、`mobile.css`、`locales.css`、动效和页脚样式、`font/`
  - `js/`：`main.js`（1640 行）和公共组件 `site-footer`、`tracking`、`background-video`
  - `assets/`：所有素材平铺，附 `manifest.json`
  - `README.md`
- 页面结构和文字都直接写在 HTML 里，源码可以直接读、直接改。

## Gameweb（线上页 f3k0dpqrdbsm）

- 交付物是“数据模型加通用运行时”：
  - `index.html`（858KB）只是首帧快照；
  - `model.json.gz` 解压后 8.4MB，内容是 Figma 节点树；
  - `runtime/` 下 17 个 `.mjs` 文件，启动时整页 `innerHTML` 重画。
- DOM 由 1235 个绝对定位的 `.ews-node` 组成，结构直接对应 Figma 图层。手工改动会在下次生成时被覆盖。
- 默认带 QA 外壳；`?product=1` 时去掉外壳，但这个模式只给机器检查用，不是为上线设计的。

## 本质区别

开发侧交付的是“源码”，Gameweb 交付的是“播放器加录像”。后面各项能否对齐，都取决于这一项。
