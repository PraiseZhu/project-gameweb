# 设计稿命名速查｜按功能找，按名字查

规则依据：v2.23 (2026-11-18)。阅读版更新：2026-11-18。本页重排说明与场景，不改变规则语义。

[完整规范](naming-spec.md) · [可搜索图文版](naming-guide.html)

## 30 秒开始

1. 分区、切图、交互或行为需要前缀；纯编组和普通 TEXT 不加。
2. 写法：`前缀/用途名称[@参数]`。例如 `btn/查看玩法@sec=2` = 可点击 + 用途 + 点击滚到第 2 屏。
3. 先按功能找，再读边界；多个能力用父子层分工，不把容器一律标成 img。

## 按命名查用途

<a id="prefix-sec"></a>
### sec/ · 页面分区

**何时用：** 把页面分成第 1、2、3 屏。

**标在哪：** 标在每个页面分区的外框。编号是排序和导航的依据。

**照着写：** `sec/1-首屏`

**边界：** 编号以正整数开头，同页不能重号。可隔着无前缀布局容器；不要嵌套 sec，也不要放在 img、switch、modal 等语义层里。各分区须属于同一逻辑父层。

依据：§1 / A2。

<a id="prefix-fix"></a>
### fix/ · 视口悬浮

**何时用：** 让导航或按钮钉在屏幕上。

**标在哪：** 标在悬浮层容器；里面能点的入口仍标 btn/。

**照着写：** `fix/侧边导航@from=2`

**边界：** 不写 @from 就进页固定；@from=2 表示从第 2 屏起出现并固定，第 2 屏必须存在。首屏随页面滚动的按钮另放在 sec/1 里。

依据：§1、§2 / A2。

<a id="prefix-grp"></a>
### grp/ · 通用模块容器

**何时用：** 把有独立语义的一组子模块作为一个整体。

**标在哪：** 标在需要被页面结构、布局、关系或验收单独识别的容器。

**照着写：** `grp/模块边界`

**边界：** 纯排版包装、遮罩和技术 wrapper 不标；具体类型明确时优先用 panel/list/card 等类型。

依据：§1 / G1。

<a id="prefix-list"></a>
### list/ · 条目集合

**何时用：** 把同类条目组织成可重复集合。

**标在哪：** 标在列表容器根；直接重复子项用 item/。

**照着写：** `list/集合`

**边界：** 需要 Auto Layout 或等价排布声明；普通排列不标。

依据：§1 / G1、G2、G4。

<a id="prefix-item"></a>
### item/ · 重复条目

**何时用：** 标记列表中的一条重复项。

**标在哪：** 标在 list/ 的直接重复子项。

**照着写：** `item/条目`

**边界：** 只在 list/ 内作为条目边界使用；内部继续按现有角色命名。

依据：§1 / G1、G2。

<a id="prefix-ref"></a>
### ref/ · 参考稿

**何时用：** 放说明稿，不交给前端做。

**标在哪：** 标在整份滚动示意、状态说明等参考内容的外框。

**照着写：** `ref/滚动效果说明`

**边界：** 整个子树被忽略，不检查、不报警。不要把真正要交付的页面或素材放进去。

依据：§1。

<a id="prefix-img"></a>
### img/ · 静态图片

**何时用：** 导出装饰图、图标、美术字。

**标在哪：** 标在要整体导出的图层；美术字即使是 TEXT，也可明确标成图。

**照着写：** `img/首屏标题`

**边界：** 不是任意外层编组都标 img。可改文字不加前缀；多语言换图看场景 F，可替换整图看 H。img 不挂 @ 参数。

依据：§1、§3 / A1、A6。

<a id="prefix-bg"></a>
### bg/ · 大面积背景

**何时用：** 导出内容背后的大底图。

**标在哪：** 标在实际的背景素材层。

**照着写：** `bg/首屏底图`

**边界：** 只表达大底图身份，不包住整屏按钮和文案。可替换标记不支持 bg，不要为了可替换而改成 img。

依据：§1、§5 / A1。

<a id="prefix-kv"></a>
### kv/ · KV 视差层

**何时用：** 让背景、角色、前景分层视差。

**标在哪：** 标在同一父层下各个要分别运动的视觉层；外面的纯编组保持原名。

**照着写：** `kv/角色@parallax=0.4`

**边界：** 系数为 0–1。只有一层无法体现视差；普通静态图用 img，大底图用 bg。KV 外层容器不要整块标 img。

依据：§1、§5 / A1。

<a id="prefix-btn"></a>
### btn/ · 可见按钮

**何时用：** 让一个可见元素可以点击。

**标在哪：** 标在实际可点击的控件根层。

**照着写：** `btn/播放@go=modal/视频弹窗`

**边界：** 可选 @link / @go / @sec / @lang；实际动作仍要配置。普通按钮内部要切的图仍需命名；布尔合成按钮整体导出，不给 Subtract 零件逐个加 img。

依据：§1、§2 / A3、A8。

<a id="prefix-hot"></a>
### hot/ · 透明热区

**何时用：** 在画面上盖透明点击区。

**标在哪：** 标在透明命中区域，而不是下面的视觉图片。

**照着写：** `hot/官网入口@link=official`

**边界：** 可用 @link、@go、@lang；不能用 @sec。可见控件用 btn，透明覆盖区用 hot。

依据：§1、§2 / A3。

<a id="prefix-modal"></a>
### modal/ · 独立弹窗

**何时用：** 点击后出现一扇弹窗。

**标在哪：** 标在独立的弹窗 Frame，放在页面正常稿之外。

**照着写：** `modal/视频弹窗`

**边界：** 入口 @go 抄弹窗完整图层名，不写 node id；目标必须唯一。多颗入口可开同一窗。窗内播放、关闭按钮不要写开窗 @go。

依据：§1、§2 / A3、A7。

<a id="prefix-dropmenu"></a>
### dropmenu/ · 开合菜单

**何时用：** 点开菜单，再点选一项。

**标在哪：** 标在菜单组件集根层；用变体表示关闭和展开。

**照着写：** `dropmenu/语言菜单`

**边界：** 状态轴的值集合必须恰好是小写 on、off，轴名不限。不能写 @on、@off、@state。PC 和手机都适用；已画成 btn → modal 的保持弹窗。

依据：§1 / A9。

<a id="prefix-dyn"></a>
### dyn/ · 动态内容

**何时用：** 显示倒计时、进度或当前选值。

**标在哪：** 标在运行时会更新的组件容器。

**照着写：** `dyn/活动倒计时`

**边界：** 内部零件免前缀语法与图像未命名报警。前缀声明动态身份，具体数据来源与业务逻辑仍由下游接入。

依据：§1。

<a id="prefix-mix"></a>
### mix/ · 图文混排

**何时用：** 保留日历、列表的图文结构。

**标在哪：** 标在日历、奖励列表等图文混排大块的容器。

**照着写：** `mix/活动日历`

**边界：** 只需命名容器，内部零件免前缀语法与图像未命名报警。无前缀图片填充叶子自动拆切图，TEXT 保留文案；不是把整块导成图片。

依据：§1 / A8。

<a id="prefix-scroll"></a>
### scroll/ · 滑动视口

**何时用：** 让列表连续横滑或竖滑。

**标在哪：** 标在可滑动的视口框；第一个子层必须是内容轨道。

**照着写：** `scroll/奖励列表@y`

**边界：** 默认横滑，也可显式 @x；竖滑写 @y。轨道直接子项是 item。普通 scroll 内图片仍需命名；在 mix 内时保留滑动和自动拆图规则。

依据：§1、§2 / A5、A8。

<a id="prefix-switch"></a>
### switch/ · 切换器／轮播

**何时用：** 轮播或切换一整份内容。

**标在哪：** 标在切换内容的容器。

**照着写：** `switch/玩法轮播`

**边界：** 页签条用 tab，圆点用 ind。不发明 swpage/。连续滚动列表用 scroll，切换整份内容才用 switch。

依据：§1 / A4。

<a id="prefix-tab"></a>
### tab/ · 页签条

**何时用：** 点击页签切换内容。

**标在哪：** 标在 switch 对应的页签条容器。

**照着写：** `tab/职业页签`

**边界：** 表达页签切换身份，不是普通外链按钮。它本身不是切图角色；内部需要独立导出的图片仍需命名。

依据：§1 / A4。

<a id="prefix-ind"></a>
### ind/ · 轮播指示器

**何时用：** 用圆点或菱形表示轮播进度。

**标在哪：** 标在指示器组件／实例；同组可同名，序号按同级排列。

**照着写：** `ind/轮播进度`

**边界：** 嵌在 switch 内可确定归属；否则最近 sec 内只能有一个 switch（无 sec 时看体检根）。组件集各变体整体切图，内部小钻石不命名。

依据：§1、§6 / A4、A8。

## 参数怎么接

| 参数 | 适用 | 作用 | 示例 | 注意 |
|---|---|---|---|---|
| `@link=<key>` | btn / hot | 跳转到配置中的链接 | `btn/官网@link=official` | 填业务 key，URL 放配置。 |
| `@go=<state>` | btn / hot | 状态转移；开窗指向弹窗名 | `btn/预约@go=modal/预约弹窗` | 开窗目标须存在且唯一；不要写图层 id。 |
| `@lang=<codes>` | 独立 btn / hot | 只在指定语言出现 | `btn/适龄提示@lang=cn` | 逗号分隔小写五码，无空格、空项、重复码；壳内和弹窗内容里禁用。 |
| `@sec=<N>` | btn | 点击滚到第 N 屏 | `btn/玩法@sec=2` | N 为正整数，对应分区必须存在。 |
| `@from=<N>` | fix | 从第 N 屏起出现并固定 | `fix/导航@from=2` | N 为正整数，分区须存在；不写则进页固定。 |
| `@parallax=<0–1>` | kv | 这层的视差系数 | `kv/前景@parallax=0.8` | 取值 0–1，需同父层多层配合。 |
| `@x / @y` | scroll | 横滑／竖滑 | `scroll/奖励@x` | 纯标记，不写等号和值；默认横滑。 |

## 场景照着搭

以下为结构示意，不是 Figma 真稿截图。普通容器名称可按项目用途填写。

### A · 一张页面：分区、固定、切图各管一层

```text
页面
├─ 页面内容（纯布局，不加前缀）
│  ├─ sec/1-首屏
│  │  ├─ bg/首屏底图
│  │  ├─ KV分层（纯编组）
│  │  │  ├─ kv/远景@parallax=0.1
│  │  │  └─ kv/角色@parallax=0.4
│  │  └─ btn/玩法@sec=2
│  └─ sec/2-玩法
└─ fix/侧边导航@from=2
   └─ btn/玩法@sec=2
```

- bg 与 KV分层是兄弟，bg 不属于 KV 的子层。KV 外层只是编组。
- sec 不必直接在页面根下，但忽略纯布局容器后应属于同一逻辑父层；不允许嵌套、重号或挂在其它语义前缀下面。
- @sec 是“点了去哪里”；@from 是“从哪里开始显示”。连续编号易读；缺号是提醒，重号是错误。

依据：§1、§2、§6 / A2。

### B · 点按钮开弹窗：名字要能一一对应

```text
页面内
└─ btn/播放@go=modal/视频弹窗

页面稿外的独立 Frame
└─ modal/视频弹窗
   ├─ btn/关闭
   └─ btn/播放
```

- 把弹窗画成独立 Frame，不叠在页面正常稿里。@go= 后面完整抄弹窗名；目标必须唯一。多颗入口可以指向同一扇窗。
- 关闭、窗内播放不写开窗 @go。透明点击覆盖区可用 hot。实际关窗、播放动作仍由下游接入。

依据：§1、§2 / A3、A7。

### C · 轮播与滑动列表：先看内容怎么动

```text
sec/3-职业
├─ switch/职业切换
│  ├─ 职业一（普通内容容器）
│  └─ 职业二（普通内容容器）
├─ tab/职业页签
└─ 指示点（纯编组）
   ├─ ind/进度
   └─ ind/进度
```

- 整份内容互相切换用 switch；一条长列表连续移动用 scroll。
- ind 与 switch 可以是兄弟：最近 sec 内只有一个 switch 就能确定。多个轮播时，把各组 ind 嵌进对应 switch。找不到或归属不明都要改。
- ind 同组可同名，序号看顺序。指示器变体整体切图，内部小钻石不标 img。组件库定义本身不参与页上联动判定，定义内实例仍正常判定。

依据：§1、§6 / A4、A8。

### D · 奖励横滑：视口 → 轨道 → 卡片

```text
scroll/奖励列表@x        ← 视口
└─ 内容轨道              ← 第一个子层
   ├─ 奖励卡片一          ← item
   │  ├─ img/金币图标
   │  └─ 金币 × 100（TEXT）
   └─ 奖励卡片二
      ├─ img/宝石图标
      └─ 宝石 × 10（TEXT）
```

- 轨道直接子项才是列表 item，不能省掉轨道。@x 横滑，@y 竖滑；不写默认横滑。
- 普通 scroll 轨道里的图片仍需 img，文字不加 txt。放进 mix 内仍是滑动视口。
- mix 内无前缀、已开裁切且子层或自身相对父层横向溢出的框，可自动识别为 scroll；图片按 mix 的条件拆出。

依据：§1、§2 / A5、A8。

### E · 菜单：开关状态与选项动作分开

```text
dropmenu/语言菜单（组件集）
├─ state=off
│  └─ img/地球
└─ state=on
   ├─ img/地球
   ├─ btn/简体中文
   │  └─ 简体中文（TEXT）
   └─ btn/English
      └─ English（TEXT）
```

- state 是示例轴名，可用 Property 1；值集合必须恰好为小写 on、off。点根开关；点行内 btn 优先执行该行；点外面关闭。
- 语言选项按可见文字认：简体中文 / 繁體中文 / English / 日本語 / 한국어（可归一空格与大小写）。其它文字当普通选项，不猜中文。
- 普通选项选完关闭；同一菜单有 dyn 则更新可见值，没有就只关闭。地球只在 off 时由程序加 hover；其它行 hover / pressdown 由程序补，选中行用稿上 highlight。

依据：§1 / A9。

### F · 多语言①：同一个位置，换一张图片

```text
img/活动标题（组件集）
├─ lang=cn
│  └─ 简体标题的内部零件
└─ lang=en
   └─ 英文标题的内部零件

页面上只放这套组件的一个实例
```

- 三条件同时满足：组件集前缀 img、属性名 lang（大小写不敏感）、至少两个不同的合法小写语言值。多轴只看 lang 轴。
- 变体保留自动名 lang=cn，不改成 img/标题-cn，也不写 img/标题@lang=cn。合法变体根整体切图，内部零件不逐个命名。
- 只有一个变体、没有 lang 轴、Property 1=cn 都不跟语言。未画全五语可出清单；切到缺失语言须显式报缺失，不能回退中文图。

依据：§1 / A8。

### G · 多语言②换整组，③只控制出现

```text
② 首屏行动区（无前缀组件集）
├─ lang=cn
│  └─ btn/预约@go=modal/手机预约
└─ lang=en
   ├─ btn/下载@link=download
   └─ btn/商店@link=store

③ 页上另一个独立入口
btn/适龄@go=modal/适龄提示@lang=cn
```

- ② 不同语言不同动作：无前缀组件集 + lang 轴，至少两个合法语言值；页面放一个实例，切语言换整棵树，变体根不切图。缺语言不回退中文。
- 每个变体可有 0、1 或多颗 btn / hot。恰好一颗且有 @go，可把开窗关系抬到页实例；多颗各走自己的动作。@go 写在内部按钮，不写进变体值。
- ③ 只限制独立入口出现：写 @lang。不写就五语都在。不要放进语言壳或画空变体；壳内按钮、img、弹窗内容禁用 @lang。声明不代表做页已接入，实际显隐需页面验证。

依据：§1、§2 / A10、A11。

### H · 整图可替换，图文与动态保留结构

```text
img/[replaceable]模块2玩法截图
└─ 图片、蒙版、形状（零件不标）

mix/活动日历
├─ 奖励图片（图像填充叶子，自动拆图）
├─ 活动说明（TEXT，仍可改字）
└─ dyn/活动倒计时
   └─ 数字与单位（零件不逐个命名）
```

- 只标最外层 img。半角小写 [replaceable] 位于 body 开头，后面用途名不能为空；它不是前缀，也不是 @ 参数。
- 用途名就是稳定 assetKey，不随文件名、赛季或导出顺序改。PC/手机同一位置用同一用途名；国内/海外各有索引。同端同语言槽不得有冲突定义，组件定义与实例引用不算重复。
- 可与 img + lang 组合：组件集根标记，合法变体继承同一 key。零件不另标；bg、kv 不支持。普通 img 不标仍正常导图，只不进替换索引。
- mix 保留图文结构，不整块烙图；dyn 声明动态内容，具体数据与业务仍要接入。

依据：§1、§3 / A8、A12。

## 多语言码对照

稿上值：cn 简体中文 · tw 繁體中文 · en English · jp 日本語 · kr 한국어。页面映射：zh-CN→cn、zh-TW→tw、en→en、ja→jp、ko→kr。CN、tc、ja-JP 不是稿上合法值；region=cn 是国服，不是语言。

## 交稿前快速自查

- **先判断需不需要前缀：** 只有切图、交互、分区、行为需要前缀。普通编组保持原名；可改 TEXT 不加前缀。美术字标 img 后，即使是 TEXT 也按图消费。
- **名字写用途，不写猜谜：** 推荐小写 + 半角 / + 用途名。前缀大小写、斜杠两侧空格、全角 ／ 兼容，反斜杠错误。容错不适用于语言码、on/off、[replaceable]。
- **只有这 19 个前缀：** 不自造 txt/、part/、swpage/、dropdown/、select/、menu/、tag/。纯布局名可保留；Group/2 等 Figma 自动类型名不当作前缀。
- **参数选填，但写了就要对：** 未知参数、空值、非法值、挂错前缀都要改。@lang 不允许重复参数、重复码、空项或空格。并非所有前缀都能挂参数。
- **同名检查有边界：** 同一父层的已命名层要能区分用途，不要只用数字掩盖不同用途。ind 同组可同名；组件集直接变体、ref 子树除外；不同语言变体内同名按钮父层不同。
- **切图看身份，不看 Export：** img / bg / kv 命名即切图意图，不必另勾 Export。Export 仅覆盖格式与倍率。不要整图包住仍需交互或改文案的结构。
- **文字尺寸与自动名：** TEXT 名等于自身文字内容（去空白）时，内容中的斜杠不触发前缀语法报警，不免其它规则。长段落定宽换行；紧凑控件定宽定高，要注意文案变化。
- **声明功能，不代表已接好功能：** btn 动作可由参数或配置提供，dyn 仍要数据，@lang 显隐仍要验。清单中 @lang 节点仍保留，不因某语言不显示就改成 unknown 或 skipped；开窗目标始终要校验。
- **体检提示与交接硬闸有区别：** 必改项要修；“必须回答”可说明接受原因；“提醒”先核实。ready 不表示所有命名都正确。出清单会拦无目标分区、指示器归属、无轨道、分区结构、非法参数等确定性错误。
- **不能用豁免跳过必改项：** 只有“必须回答”和“提醒”能按条件豁免；需结构条件、命中范围、有效期与复审。完整 26 条错误码见正文 §6；豁免机制见 §7。
